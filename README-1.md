# ملف الأداء الوظيفي الإلكتروني لمعلمة رياض أطفال

مشروع جاهز للرفع على GitHub Pages. التصميم عربي RTL بألوان فاتحة ومناسب لرياض الأطفال، ويحتوي على:

- صفحة غلاف وهوية المعلمة.
- الرؤية والرسالة والأهداف.
- 11 فاصل لعناصر تقييم الأداء الوظيفي للمعلمين.
- أمثلة تحقق العنصر والشواهد المقترحة لكل عنصر.
- باركود QR تلقائي لكل عنصر وكل شاهد.
- قسم الوحدات التعليمية: وحدة الماء، وحدة الألوان، وحدة العائلة.
- تفرع داخل كل وحدة: اللقاء الصباحي، القراءة الجهرية، النشاط الأكاديمي، اللعب الخارجي، الركن الفني، الختام.
- قسم الخطط العلاجية لطفلين بصيغة آمنة: الطفل (أ)، الطفل (ب).
- قسم المبادرات والفعاليات.
- نماذج تقارير جاهزة للنسخ.
- زر طباعة / حفظ PDF.
- بحث داخل الملف.
- وضع ليلي اختياري.

## طريقة التعديل السريعة

كل البيانات موجودة في:

```text
assets/js/data.js
```

عدلي فقط هذا الملف لإضافة اسم المعلمة، اسم الروضة، الروابط، أسماء الوحدات، أو الشواهد.

مثال إضافة رابط صورة أو مقطع:

```js
{ title: "القراءة الجهرية", type: "مقطع", mediaUrl: "https://drive.google.com/...", description: "وصف مختصر" }
```

إذا كان `mediaUrl` فارغاً، سيظهر في الموقع أنه بانتظار إضافة الرابط، وسيولد QR داخلي للفاصل نفسه.

## رفع المشروع على GitHub Pages

1. أنشئي مستودعاً جديداً في GitHub.
2. ارفعي جميع الملفات والمجلدات كما هي.
3. من Settings ثم Pages اختاري الفرع `main` والمجلد `/root`.
4. بعد ظهور رابط GitHub Pages، افتحي الموقع وستتولد أكواد QR تلقائياً حسب الرابط الجديد.

## ملاحظات الخصوصية

- لا تضعي أسماء الأطفال الحقيقية في النسخة العامة.
- استخدمي رموزاً مثل الطفل (أ) والطفل (ب).
- يفضل طمس الوجوه أو استخدام روابط خاصة عند إرفاق صور ومقاطع الأطفال.
