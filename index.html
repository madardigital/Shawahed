الرؤية والرسالة والأهداف

قسم تعريفي يمكن وضعه في بداية ملف الأداء الوظيفي.

فواصل عناصر تقييم الأداء الوظيفي

كل عنصر يحتوي الوزن النسبي، أمثلة تحقق العنصر، الشواهد المقترحة، وQR خاص.

باركود الوحدات التعليمية

فاصل رئيسي للوحدات، وكل وحدة تتفرع إلى ملفات للصور والمقاطع.

الخطط العلاجية والمتابعة الفردية

قسم مخصص للأطفال المحتاجين إلى خطة علاجية، مع فصل مستقل لكل طفل.

المبادرات والفعاليات

تقارير جاهزة قابلة للتعديل لليوم الوطني، يوم التأسيس، القراءة، الأنشطة الصحية، وغيرها.

نماذج التقارير الجاهزة

نصوص مختصرة بصياغة مهنية يمكن نسخها أو طباعتها وإرفاق الصور والمقاطع معها.

مصادر الاعتماد

  • وزارة التعليم: الرؤية والرسالة والأهداف.
  • الدليل المبسط لتقييم أداء شاغلي الوظائف التعليمية.
  • ملف أداء وظيفي إلكتروني بصياغة عربية RTL جاهز للرفع على GitHub Pages.
